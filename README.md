# ⚡ Client Lead CRM

A simple and professional Client Lead Management System (Mini CRM) built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## 📌 Project Overview

Client Lead CRM helps businesses manage potential customers (leads) in one place.

Users can add, view, edit, search, update, and delete leads while tracking their current status.

## ✨ Features

- ➕ Add new leads
- ✏️ Edit lead details
- 🗑️ Delete leads
- 🔍 Search leads
- 📊 Dashboard statistics
- 🔄 Update lead status
- 📝 Add notes and follow-up details
- 📧 Store email information
- 📞 Store phone numbers
- 🏢 Store company details
- 🌐 Track lead source
- 💾 MongoDB database storage
- 📱 Responsive dashboard design

## 🔄 Lead Status

Leads can have three different statuses:

- 🆕 New
- 📞 Contacted
- 🎯 Converted
